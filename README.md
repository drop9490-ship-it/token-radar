Token Radar ranks 198 pre-token DeFi protocols by implied launch value — a sector multiple calibrated from the snapshot's own live-token market, plus growth, maturity and chain breadth — and gives each one a concrete farm plan with costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
